\section{Run Commands}
\label{app:commands}

Each experiment is fully specified by the layered configuration files
(policy, experiment, hardware, and --- for the scaling arm --- model) plus
explicit index paths and an output log. Representative commands:

\begin{lstlisting}[language=bash,caption={Main MCQ runs on the real corpus (3B, CPU).}]
python scripts/run_experiment.py \
  --policy     configs/policies/p1_always_retrieve.yaml \
  --experiment configs/experiments/mirage_medcorp.yaml \
  --hardware   configs/hardware_medium.yaml \
  --dataset    data/raw/mirage/benchmark.json \
  --model      models/Llama-3.2-3B-Instruct-Q4_K_M.gguf \
  --bm25-index indexes/bm25_medcorp_tp.pkl \
  --faiss-index indexes/faiss_medcorp_tp \
  --retrieval-mode hybrid --max-questions 200 \
  --output     results/raw_logs/p1_medcorp_mcq.jsonl

python scripts/run_experiment.py \
  --policy     configs/policies/p5_gated_entropy.yaml \
  --experiment configs/experiments/mirage_p5_calibrated.yaml \
  --hardware   configs/hardware_medium.yaml \
  --dataset    data/raw/mirage/benchmark.json \
  --model      models/Llama-3.2-3B-Instruct-Q4_K_M.gguf \
  --bm25-index indexes/bm25_medcorp_tp.pkl \
  --faiss-index indexes/faiss_medcorp_tp \
  --retrieval-mode hybrid --max-questions 200 \
  --output     results/raw_logs/p5_medcorp_mcq.jsonl
\end{lstlisting}

The scaling runs are the identical command with two additions: a
\texttt{--model-config} naming the model's chat format and calibrated gate
thresholds, and the corresponding GGUF file.

\begin{lstlisting}[language=bash,caption={Scaling arm (Qwen2.5-14B); only the model and its config change.}]
python scripts/run_experiment.py \
  --policy       configs/policies/p5_gated_entropy.yaml \
  --experiment   configs/experiments/mirage_p5_calibrated.yaml \
  --hardware     configs/hardware_medium.yaml \
  --model-config configs/models/qwen14b.yaml \
  --dataset      data/raw/mirage/benchmark.json \
  --model        models/Qwen2.5-14B-Instruct-Q4_K_M.gguf \
  --bm25-index   indexes/bm25_medcorp_tp.pkl \
  --faiss-index  indexes/faiss_medcorp_tp \
  --retrieval-mode hybrid --max-questions 200 \
  --output       results/raw_logs/p5_qwen14b_mcq.jsonl
\end{lstlisting}

Both are wrapped by \texttt{scripts/run\_overnight.bat}, which re-launches
each step until its log holds all 200 records --- safe because runs resume by
skipping already-logged \texttt{question\_id}s.

\begin{lstlisting}[language=bash,caption={Corpus build (resumable, shard-checkpointed).}]
python scripts/build_medcorp.py --sources textbooks pubmed \
  --limit-pubmed 300000 --name medcorp_tp
\end{lstlisting}

\begin{lstlisting}[language=bash,caption={Offline analyses (no model calls).}]
python scripts/run_threshold_sweep.py    # calibration replay
python scripts/run_gate_ablation.py      # signal agreement / swing
python scripts/run_gate_variants.py      # voting-rule sweep
python scripts/analyse_chunk_relevance.py
python scripts/generate_tables.py        # numbers.tex + tables
python scripts/generate_figures.py       # all figures
\end{lstlisting}

at load time via the canonical loader (\texttt{evaluation/loading.py}).

\section{Test Inventory}
\label{app:tests}

227 tests pass at the time of writing (\texttt{pytest -q}, 95\,s, no model
required), spanning unit (configuration, retrieval, gates, policies, scoring, metrics),
integration (open-ended path end-to-end), and regression suites (number
drift guard; P3 paired-run corpus independence). The suite runs without the
model or any dataset download via \texttt{MockLLMBackend}:

\begin{lstlisting}[language=bash]
python -m pytest -q          # full suite, ~seconds, no model required
\end{lstlisting}

\section{Corpus and Index Parameters}
\label{app:corpus}

\begin{itemize}
  \item Sources: MedRAG/textbooks (\(\sim\)126K snippets) + MedRAG/pubmed
    slice (300{,}000 snippets); total \textbf{425{,}847 chunks}.
  \item Embedding: \texttt{all-MiniLM-L6-v2}, 384-d, L2-normalised;
    shard-checkpointed (2{,}000 chunks/shard).
  \item Indexes: FAISS \texttt{IndexFlatIP} (654\,MB, exact) and BM25
    (787\,MB).
  \item Model: Llama-3.2-3B-Instruct Q4\_K\_M (GGUF), \texttt{llama.cpp},
    CPU-only, temperature 0, fixed seed.
  \item Calibrated gate thresholds: \(\tau_H = \tau_M = 0.70\);
    probe agreement threshold \(F_1 = 0.7\); ensemble \(v_{\min} = 2\).
\end{itemize}
